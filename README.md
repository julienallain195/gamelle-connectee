# 🐱 Gamelle Connectée

Surveillance de gamelle pour chat : Raspberry Pi 4/5 + caméra + app mobile React Native + Firebase.

## 📦 Structure

- `mobile-app/` → app React Native (Expo)
- `raspberry-pi/` → code Python du Pi
- `backend/` → règles Firebase
- `docs/` → documentation

## 🚀 Démarrage

Pi : `cd raspberry-pi && pip install -r requirements.txt && python src/main.py`

App : `cd mobile-app && npm install && npx expo start`
