# 🛠️ Matériel nécessaire
   Composant | Recommandation | Prix indicatif |
 |---|---|---|
 | Raspberry Pi | Pi 5 (4 Go) ou Pi 4 (4 Go) | 60-80€ |
 | Caméra | Caméra officielle Raspberry Pi v3 | ~35€ |
 | Carte microSD | 32 Go minimum | ~10€ |
 | Alimentation | Alim officielle USB-C (27W Pi 5 / 15W Pi 4) | ~10€ |
 | Boîtier | Avec emplacement caméra | ~10€ |
 | Optionnel : capteur de poids HX711 | Détection du niveau de croquettes en complément de la caméra | ~5€ |

## 📐 Montage suggéré

Caméra fixée AU-DESSUS de la gamelle (hauteur ~30-50 cm),
pointée vers le bas. Le Pi posé à côté.
Astuce : un fond contrasté (tapis noir sous la gamelle) améliore la détection.
